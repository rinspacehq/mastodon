# Shared-theme compatible release

This maintenance image retains the exact accepted parent-session-recovery base,
gems, database compatibility, runtime configuration and worker image. It adds
the raw inline prepaint script and **fully rebuilt** Vite production packs. It
does not replace a production volume or patch minified assets.

Build from the exact clean reviewed public commit with Node 22 or newer and the
unchanged frozen yarn.lock. Install dependencies without secrets, then run
`node scripts/rinspace-theme-assets.mjs build` in an isolated environment with
no network or production mounts. The product build verifies the dependency
cache's matching lock before mounting it read-only. Assets must be built once;
the inventory binds every generated byte to the source commit. Verify using
`node scripts/rinspace-theme-assets.mjs verify` before packaging.

Load the base image from the matching public parent-recovery release and build
`Dockerfile.rinspace-theme` with `--pull=false --network none` and the exact
`SOURCE_COMMIT`. Distribute the immutable image, SBOM, complete corresponding
fork source and the assets inventory together. Product acceptance and protected
Web-only rollout are separate gates; do not restart Sidekiq or run migrations.
Existing content-hashed base assets can remain for already-open old clients;
the newly generated manifest and service worker select the new complete build.
